# Tutorials index

This directory contains Master-level tutorials for the Quantum_Agrivoltaic_PT-HOPS project.

Included so far:

- 00-onboarding/: Environment and quick start
- 03_pt_hops/: Minimal PT-HOPS pedagogical demo (script + README)

How to use

1. Create the environment:

   conda env create -f tutorials/00-onboarding/environment.yaml
   conda activate qa_pt_hops_tutorial

2. Run the PT-HOPS demo (quick):

   python tutorials/03_pt_hops/03_pt_hops_minimal_demo.py
