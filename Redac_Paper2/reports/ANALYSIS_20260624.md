## 3. Goulots d'étranglement réels

**Le goulot principal est le calcul MesoHOPS lui-même**, pas la parallélisation :
- 5000 pas de temps × 135 modes de hiérarchie × L=8
- Chaque pas ≈ 336 ms à 99.9% CPU (1 thread, 3 GHz)
- 45-50 min/traj

Les optimisations Python (JIT, dict, update_step, TAU) ont un impact ~10-20% sur ce temps,
tandis que la contention CPU (fixée par `OPENBLAS_NUM_THREADS=1` + `MAX_N_JOBS=8`) évitait
un ralentissement 5×.
